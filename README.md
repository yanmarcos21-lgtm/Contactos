# Lista de contactos

Proyecto de la **Lista de tareas**: formulario para registrar contactos con HTML, CSS y JavaScript.

## Descripción
El formulario recibe nombre, apellido, teléfono, ciudad, dirección y género. Al pulsar **ADD**, el contacto se valida y se muestra en la lista, donde también se puede eliminar.

## Archivos
- `index.html`: estructura del formulario y de la lista.
- `styles.css`: estilos (fondo amarillo, título blanco, botón azul) y diseño adaptable a móvil.
- `script.js`: validación de campos, agregar y eliminar contactos.

## Cómo usarlo
1. Descarga o clona el repositorio.
2. Abre `index.html` en el navegador.
3. Completa el formulario y pulsa **ADD**.
